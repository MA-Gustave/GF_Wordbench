# Validation profile coverage matrix

## Purpose

This matrix maps profile policy to executable checks and current-run evidence.
It does not define language identity or source location.

## Levels

- `SMOKE`: fast structural or representative check;
- `NORMAL`: standard development validation;
- `RELEASE`: required release evidence.

## Compendium TEST_RGL mapping

Profiles intended for language certification should map their executable checks
to the Compendium evidence ladder. Compilation alone does not satisfy the
linguistic levels. Use `not_assessed` when the run did not execute the required
evidence.

| TEST_RGL level | Evidence class | Typical Wordbench evidence |
|---|---|---|
| `T0` | environment/source integrity | GF version, source lock, resolved paths |
| `T1` | resource/prelude layer | targeted resource compile/scenario |
| `T2` | morphology | morphology scenarios + reviewed goldens |
| `T3` | paradigms | paradigm scenarios + reviewed goldens |
| `T4` | basic constructors | constructor scenarios |
| `T5` | feature interactions | cross-feature scenarios |
| `T6` | questions/relatives | dedicated syntax scenarios |
| `T7` | module composition | checkpoint/entrypoint compilation |
| `T8` | aggregate language compile | complete RGL census compile |
| `T9` | parse/linearize behavior | parse, linearize, round-trip scenarios |
| `T10` | regression | reviewed regression treebank/goldens |
| `T11` | release evidence | all applicable release gates and limitations |

## Matrix template

| Coverage ID | Level | Requirement | Owner | Check | Expected evidence | Required |
|---|---|---|---|---|---|---|
| `COV-COMPAT-001` | NORMAL | expected language key matches | profile compatibility | compatibility validation | structured result | yes |
| `COV-SOURCE-001` | NORMAL | selection remains inside resolved language | selection service | source selection | selected-file inventory | yes |
| `COV-ENTRY-001` | NORMAL | required entrypoints exist | profile module policy | inventory check | module findings | yes |
| `COV-CHECK-001` | NORMAL | checkpoints pass in order | profile module policy | compile/load checks | checkpoint results | as declared |
| `COV-SCENARIO-001` | NORMAL | required scenarios pass | scenario registry | scenario execution | scenario result | as declared |
| `COV-GOLD-001` | NORMAL | required golds match | scenario/gold policy | normalized comparison | comparison result | as declared |
| `COV-RELEASE-001` | RELEASE | release entrypoints pass | release policy | compile/load checks | release evidence | as declared |
| `COV-ARTIFACT-001` | RELEASE | expected artifacts exist and verify | release policy | artifact verification | manifest records | as declared |

Replace example rows with profile-specific rows. Stable generic rows may remain
when they describe actual reusable checks.

## Traceability rules

Every required profile item must map to at least one coverage row:

- required entrypoint;
- checkpoint;
- required scenario;
- required gold;
- release artifact;
- release gate.

Every row must identify its owner and evidence. File existence alone is not
sufficient evidence for behavioral requirements.

## Prohibited rows

Do not add rows asserting that the profile owns:

- the active language identity;
- the selected language directory;
- the RGL installation path;
- the GF executable;
- the run output directory.

Those concerns are tested through their actual owners.

## Completion checklist

- [ ] all required profile policy mapped
- [ ] no duplicate coverage IDs
- [ ] all checks executable
- [ ] evidence generated by the current run
- [ ] release rows agree with release criteria
- [ ] optional rows are clearly non-blocking
