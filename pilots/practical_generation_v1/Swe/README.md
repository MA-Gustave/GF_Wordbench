# Ars Magna Defluens — practical pilot Swe

15 **isolated GF source probes** using RGL `SyntaxSwe` and `ParadigmsSwe`.
The selected language is `gf-rgl/src/swedish`.

These are **provisional test materials**, not validated linguistic translations.
No `.gold` files are approved. A syntactically compilable probe does not establish
practical coverage; WordBench must generate real output, a reviewer must assess
each sentence and approve a canonical gold before status `passed` is justified.

Do not edit GF inputs without regenerating scenario SHA locks using
`python tools/generate_practical_pilots.py`.
